---
name: video-editing
description: Guidance for combining ordered video URLs and choosing transitions with the Magica merge video tool.
---

Use this skill when the user asks to combine, stitch, concatenate, or merge multiple videos.

Preserve the user's original video order. Use `merge_videos` with 2 to 100 URLs. Choose `none` for direct joins, `fade` for gentle transitions, and `dissolve` when the user asks for a blended cinematic feel.

If fewer than two video URLs are available, ask for the missing inputs instead of calling the tool.
