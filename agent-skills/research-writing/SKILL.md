---
name: research-writing
description: Guidance for producing clear written answers while respecting tool outputs and conversation context.
---

Use this skill when the user asks for planning, summarization, explanation, or a polished written response.

Ground the final response in the current conversation and completed tool results. Do not invent provider outputs. If a tool failed, explain the safe error and suggest the next concrete retry path.

Keep answers direct and structured around what the user can do next.
